    (01) — Abstract
    // Why this exists

    An olfactory decoder distilled from biology.

    植物在染病初期釋放的揮發性有機化合物（VOCs），是極具價值的早期求救訊號 — 卻幾乎沒有現有感測技術能在田間環境中精準聽見它。

    AeroSense Bio 突破傳統硬體限制，利用表現果蠅嗅覺受體的活體細胞陣列作為感測核心，發揮自然界千萬年演化出的極致靈敏度。

    在運算後端，導入仿生資料處理演算法，將高維度的螢光動態訊號轉化為精準的疾病辨識結果。低功耗、高專一性、可自我修復 — 並能無縫部署至邊緣運算裝置。

    (02) — Research
    // Three core modules

    Bottom-up, two tracks, one stack.

    M·01 / Bio-Sensing

    昆蟲嗅覺受體之異源表現

    以 HEK293T 為平台，雙質體共轉染策略快速建立氣味感測元件。GCaMP6 螢光動態驗證受體活化，並導入 AlphaFold 與分子對接進行 AI 輔助蛋白突變優化。

    HEK293T GCaMP6 AlphaFold
    M·02 / Neural Compute

    仿生神經運算與深度學習

    模擬果蠅觸角葉（AL）側向抑制與蕈狀體（MB）的局部敏感雜湊（LSH）稀疏編碼。將高維螢光矩陣轉為精準分類，活體雙光子鈣離子造影提供生物學基準。

    AL · LN MB · LSH Sparse
    M·03 / Cross-species

    哺乳動物嗅覺仿生平台

    PC12 神經細胞系表現狗、貓與人類特異性 OR、伴侶蛋白 RTP1S 與 Gαolf。透過 cAMP 與鈣離子訊號比較跨物種靈敏度，作為次世代感測升級基礎。

    PC12 GPCR RTP1S
    (03) — Hardware
    // Bedside edge platform

    A disposable cartridge for live tissue.

    03
    FormBedside terminal
    SampleExhaled gas
    Optics488 nm LED
    ComputeEdge AI
    Step A

    Disposable ALI bio-cartridge.

    聚碳酸酯奈米微孔濾膜載體，PDL 生物錨定搭配低熔點洋菜膠相變固水技術，徹底消除運送途中之液面搖晃，把活體細胞陣列做成可拋棄的耗材單元。

    Step B

    Direct gas perfusion.

    微型氣泵以低流速導入呼出氣袋檢體；串聯氣道確保陣列濃度一致；0.22 µm 醫療級濾嘴維持生物安全。

    Step C

    Incubation & light shield.

    Peltier 致冷／加熱晶片搭配 PID 控制，37 °C 恆溫誤差 ± 0.2 °C；卡扣 + O-ring 達成絕對物理避光，杜絕外部光源干擾螢光擷取。

    Step D

    Optical readout, edge inference.

    488 nm LED + 帶通濾光片擷取 ΔF/F₀；雙腦架構（Arduino 控制 + Raspberry Pi 推論）本地端執行類觸角葉神經網路模型，毫秒級回傳分類結果。

    (04) — Roadmap
    // Five-month sprint

    POC, compressed. Rigorous, fast.

    M.01 / Apr
    — · Setup

    Plasmid build + optical rig.

    完成 HEK293T 雙質體序列建構與擴增；備妥基礎光學觀測環境。

    M.02 / May
    Checkpoint 01

    Cell-line POC.

    觀測 VUAA1 激發之螢光動態反應；同步完成哺乳動物 OR 系統質體設計。

    M.03–04 / Jun–Aug
    Checkpoint 02

    Fluorescence matrix + receptor optimisation.

    產出果蠅 OR 陣列基礎螢光資料矩陣交予 DL 團隊；完成計算生物學受體突變優化；啟動 PC12 轉染與功能驗證。

    M.05 / Sep
    Checkpoint 03

    Integrated MVP.

    完成高通量氣味刺激測試與 DL 演算法分類準確率驗證；產出初代生物感測 MVP。

    (05) — Why it matters
    // Innovation & value

    Three angles, one platform.

    i.01 / Academic

    學術創新

    首創將活體哺乳動物細胞之異源表現陣列直接對接果蠅大腦演算法，為神經形態運算提供真實生物訊號來源。

    i.02 / Material

    解決材料老化痛點

    細胞自我更新能力，從根本解決傳統金屬氧化物感測器的材料疲勞與基線漂移，大幅延長感測器壽命與穩定性。

    i.03 / Edge AI

    邊緣運算潛力

    LSH 演算法忠實還原昆蟲大腦極高能效比，輕量化架構適合部署於低功耗邊緣晶片，廣泛應用於溫室監測與工業氣體洩漏追蹤。
